# Truck Transport App - Backend API

A Node.js/Express backend for the Rapido-like truck transport platform.

## 📦 Features

- User authentication (JWT)
- Booking management
- Driver management
- Real-time tracking
- Payment processing
- Admin dashboard API

## 🛠️ Tech Stack

- Node.js + Express
- PostgreSQL
- Redis
- Socket.io
- JWT Authentication

## 📂 Project Structure

```
backend/
├── src/
│   ├── config/
│   ├── controllers/
│   ├── models/
│   ├── routes/
│   ├── middleware/
│   ├── utils/
│   └── server.js
├── .env.example
├── package.json
└── README.md
```

## 🚀 Setup

1. Install dependencies: `npm install`
2. Configure `.env` file
3. Run migrations
4. Start server: `npm run dev`
